# M2.5-D8-A — Bootstrap, Legacy Migration and Initial Recovery

Internal composition of D8.1, D8.2 and D2–D7. No operational CLI changes.
This report includes the original implementation and the hardening of the
BLOCKER/HIGH/MEDIUM/LOW findings. No commit or push was performed.

## Architecture and APIs

The caller continuously holds exclusive `ProjectionState`, after any existing
TransactionLease, and excludes equivalent-authority writers and mount changes.
Generation, store and projection authority directories already exist. State is
revalidated against its retained inode and mount. No manager method or
TransactionPins constructor runs under that State lease.

| API | Contract |
| --- | --- |
| `inspect_initial` | Authority observation: Fresh, VerifiedPreparation, RecoveryRequired, LegacyEmpty, LegacyNonempty or Selected. Conflicts are structured errors; observation never grants ownership. |
| `ensure_initial_generation` | Publishes/resynchronizes only canonical modern empty generation 0, without current. Complete preparations can be verified; incomplete ones are preserved and refused. |
| `bootstrap_initial` | Generation 0 preparation, D2 → D8.1/D4 → D6 → D7. Empty historical selection is converted at the same generation using EmptyOwnership. |
| `migrate_initial` | Explicit C binding, D2, fresh D3 seals/adoption within the exclusion interval, D8.1/D4 → D6 → D7. Same-generation conversion. |
| `recover_initial` | Independently observed exact CurrentV1 identity → D6 barrier recovery → mandatory D7. No candidate plan is selected by enumeration. |
| `AuthorityContext::inspect_binding(StoreGcLock)` | Read-only binding inspection before selection, without current or pin registration. Both records absent means unbound; partial, corrupt, unsafe and mismatched records fail closed. |
| Preserving `validate_binding` / `atomic_replace` overloads | Existing C binding publication protocol and barriers, with `ReplacementFailure::Preserve`. Original signatures and cleanup behavior remain available to existing callers. |

Typed StoreGc acquisitions occur after caller-owned State and finish before any
D3/D6/D7 call that acquires StoreGc itself. There is no recursive State or StoreGc
acquisition. Binding observation itself writes no authority/pin records; lock-file
acquisition can create the existing lock infrastructure.

## Corrected findings

**BLOCKER — store/generation authority.** All initial operations inspect the C
binding, including tree-only migration. A store already bound to G1 cannot be
adopted for G2. Explicit nonempty migration establishes the existing C protocol's
binding under State → StoreGc before D3, without registering a transaction.
Complete existing records are validated; partial records are never synthesized.
Recovery also refuses a preexisting nonempty selected generation without a
complete C binding, preserving current and creating no authority. Empty fresh
selection may legitimately precede pin registration.
State blocks the bound authority's GC throughout D3–D7; a different authority
cannot obtain deletion authority over that store. Nonprivileged regressions use
G1/G2/S and verify refusal before D2, unchanged historical current and no selection.

**HIGH — D6 pre-rename retry.** A `.athena-current-<id>` is not fresh. It must be a
private, canonical CurrentV1 preparation for generation 0, with exact filename,
matching canonical absent-base D8.1 digest and matching published D4 identity.
General inspection returns RecoveryRequired. Only an explicit bootstrap request
with the same ActivationId can resume, reconstructing the identical base,
generation bytes and digest and reusing D8.2/D6 checks. Different identities,
corrupt/incomplete content and unknown residues are refused. Recovery never
promotes the preparation or an unselected plan.

**HIGH — legacy metadata versus C.** Conservative option B is implemented.
Before binding/selection, all numeric retained roots must satisfy GC directory
0700/file 0600, owner, link-count and mount constraints; generation documents are
read and validated. Directory 0755 or document 0644 produces
LegacyMetadataUnsupported, preserving original bytes and permissions. There is
no implicit chmod/conversion or new ownership protocol. Compatible empty legacy
conversion is tested through subsequent TransactionPins registration and GC.

**MEDIUM — classification and durability.** Truly absent initial authority is
Fresh. Canonical generation 0, a complete canonical zero preparation, or complete
D2 preparation is VerifiedPreparation. Incomplete or foreign zero preparations
are rejected during inspection, never described as fresh. A complete C binding
with missing current is conflicting, not a new installation. Zero publication
has file barrier → directory barrier → NOREPLACE rename → authority barriers;
current is written exclusively by D6. Generation documents are immutable across
conversion. HistoricalCurrent preserves the exact optional LF; malformed byte
variants are rejected. Tests compare complete CurrentV1, generation ID/document
bytes/digest, historical base/EmptyOwnership, ActivationId and PlanDigest.

**MEDIUM — witness and fixture isolation.** Migration witnesses derive from the
actual KeepLink operation, rather than a hardcoded operation number. VM fixtures
also compare the original and successor link inode. Every previously fixed /tmp
fixture in registered tests now reserves a private mkdtemp root; clock-only
fixture names are replaced too. Cleanup only addresses its invocation's root.
The reserved root remains present until its single RAII cleanup; old startup
and duplicate final remove_all calls are removed, avoiding a name-reuse window.
The unregistered, opt-in network `arch_repository_live_test` is not executed.

**LOW — error attribution.** Binding opening and current observation have separate
error boundaries. GenerationRead, CurrentObservation, StoreBinding, GenerationZero,
Migration and Recovery distinguish failures. Original exception_ptr preserves
exception type, errno and diagnostic. Mutation/selection uncertainty remains
conservative, including generation reads after mutation. No error authorizes
rollback, discard or cleanup.

**Additional HIGH — nested GC roots and administrative locators.** GC now retains
both the exact authoritative legacy path and its containing top-level candidate,
for generation roots AND D5 plan references. This uses only persisted references,
not scan-derived ownership, and adds bounded storage rather than all ancestors.
A nonprivileged regression exercises real GC over a nested legacy root inside a
collectable parent and verifies the payload survives. D3 refuses store lock/trash
administration as a source; D8 preflight rejects those locators before binding,
including across retained roots. Original D5 authority/retention rules are unchanged.

**Additional hardening.** Initial C authority publication now preserves even its
private temporary files after ENOSPC or pre/post rename failure. This changes no
binding format, barrier order, or default behavior of existing primitive callers.
Partial C binding retries return a structured conflict. Test targets retain assert
checks in Release using -UNDEBUG; production Release flags are unchanged.

## Recovery and exclusion limits

D2 has no finish/recovery API. Partial, mismatched or unsafe D2 binding returns
BindingRecoveryRequired with the original exception where available. No missing
administration directory, binding record or child is invented. Incomplete zero
or C binding preparations similarly require future explicit disposition.

D3 ownership comes only from explicit adoption of persisted membership, verified
source identities and hard-link witnesses. Seals/inventories are freshly checked
inside the current exclusion interval, including on retries. No scan creates
ownership and no proof survives as an execution capability across exclusion.

After an uncertain D6 rename, CurrentV1 visibility alone is insufficient. D6
recovery resynchronizes current and its authority, then D7 reconciles the exact
selected identity. Bootstrap/migration reject an already selected installation;
the explicit recovery API completes it. Published but unselected plans remain
unselected. Generation roots, plans, witnesses and uncertain preparations are
preserved. No pin retirement is part of the coordinator.

TransactionPins initialization belongs after successful selection and release of
State. The tests then reacquire State for recovery; registration is distinct from
store/generation authority binding. D5 retention is unchanged and its complete
nonprivileged tests are part of the qualification.

external equivalent-authority writers are not qualified here. Successful physical
nonempty migration, including alias/artifact branches and its added assertions,
requires the Debian VM's scanner prerequisites. No scanner contract is weakened.
