# M2.5-D6 — durable selection

Baseline: main at db0fced. Internal API only; D8 command orchestration is separate.

## Contract fixed before implementation

Publication (D4) retains an immutable intent/plan pair. It does not select it.
Commit requires an independently supplied activation ID/digest, recovers only the
published pair, checks D5's entire retention inventory, exact base current bytes,
both exact generation document digests, and complete generation membership.
State is exclusive and retained throughout; StoreGc is acquired only after State.
Equivalent-authority external writers and privileged mount changes must be excluded.

A fresh absent base is authorized only for an empty generation 0, empty plan,
and projection containing only its D2 administration. Historical bases with
EmptyOwnership require empty membership; D8-A permits any historical generation
ID satisfying this condition. Nonempty historical bases
require explicit D3 adoption. EmptyOwnership never authorizes payload removal.

Before first commit all base links must have their exact old witnesses and every
base directory must be safely traversable. A v1 base must name a published exact
predecessor plan whose desired links/witnesses match the new plan's old side.
Thus incomplete reconciliation cannot silently become a new starting state.

CurrentV1 is the sole selection authority. A mode-0600 exclusive preparation is
written and fsynced in the generation authority, then atomically renamed to
current under State after exact revalidation. Absent publication uses NOREPLACE.
The generation parent is fsynced. Existing preparations must match exact bytes;
conflicting or incomplete preparations are preserved. No discovered preparation
is promoted. Explicit commit retry may reuse only its exact preparation.

Recovery of an already selected exact CurrentV1 synchronizes its current file
instance and parent; recovery never changes a still-selected base. Visibility
after a failed barrier is uncertain until recovery succeeds. Selection recovery
does not claim payload completion. Unrelated selection, missing plans, bad
digests, corrupt metadata and unsafe mounts fail closed.

## Integration and completion

D7 takes the independently expected selected plan identity and verifies exact
CurrentV1 before mutation. Completion is a fresh physical observation of all
desired witnesses/directories and absent removed paths, not a persisted terminal
status. D9 status placement and cleanup policy are not defined here. All plans,
predecessor witnesses and ambiguous residue remain retained.

GenerationManager reads both strict current formats. Its legacy switch is forbidden
when a D2 binding exists, including malformed/partial bindings; it cannot overwrite
CurrentV1 through the old activation path. No production CLI is integrated.

## API, validation and limits

See `src/activation/selection.hpp` and the D7 document for the shared authorization
boundary. Source verification is mandatory, including unused declared sources.
Ordinary scanner privilege gates remain unchanged; no metadata inspection bypass.
Process death tests qualify namespace mechanics, not physical power loss (D10).
Test execution results and the final coverage matrix are recorded after validation.

## API and audit decisions

| API | Meaning | Payload effects |
| --- | --- | --- |
| `inspect_selection(context, State)` | Exact safe optional current record observation; no durability inference | None |
| `commit_selection(context, State, expected)` | Explicit compare-base and atomic CurrentV1 publication, or exact target retry | Base verification/barriers only |
| `recover_selection(context, State, expected)` | Re-establish target barriers, or report `BaseSelected` without promotion | None |
| D7 `inspect_reconciliation` | Complete/incomplete physical observation; ambiguity is an error | No namespace changes |
| D7 `reconcile_selection` | Execute/repeat only the exact selected plan | Authorized operations only |

`SelectionResult::TargetSelected` after successful commit/recovery establishes
selection durability under the storage contract. `inspect_selection` deliberately
remains usable when payload/source verification is unavailable; it does not
validate plan execution or claim that an earlier uncertain barrier succeeded.
Malformed/unsafe current fails rather than becoming an absent base.

The common `ExecutionAccess` boundary is private and available only to these
entry points. Its derived operation maps never escape as caller-constructible
execution capabilities. Every invocation obtains fresh D4 recovery, a complete
D5 inventory, exact generation observations and verified source membership under
one held exclusive State interval. No recursive State acquisition is used.

The B/C audit established that generation publication retains all memberships,
C pins may name absent payloads, and D5 declarations are lifetime roots rather
than availability evidence. Artifact execution therefore verifies C's exact
store/generation binding under StoreGc, verifies/scans the object, reuses B's
payload synchronization mechanics, synchronizes its ancestor namespaces, checks
the root instance and verifies again. No publication, chmod, source copying or
namespace initialization occurs. B's per-operation `Syscalls` seam handles
source barriers; `ProjectionIo` handles current/projection/D4 barriers. D3 seals
are independently verified and synchronized on each use, never silently rewritten.
Sources and equivalent-authority writers must remain quiescent throughout.

The execution inventory adds bounds of 262,144 derived source entries and 64 MiB
of path/locator bytes; these are cumulative budgets, independent of D1/D4/D5
limits. Lookup uses source identity indexes rather than generation-by-source
quadratic matching. Modern target environment semantics retain the existing
installed-environment validation; historical metadata is not rewritten.

GenerationManager's safe compatibility reader accepts strict historical bytes
and CurrentV1. Legacy initialization cannot synthesize a current record in a
bound namespace. Legacy switching cannot mutate a bound projection or overwrite
CurrentV1 even if its binding leaf is missing. Creating unselected generations,
discard protection and GC retention retain their B/C/D5 contracts.

## State and failure matrix

| Observation/action | Result |
| --- | --- |
| Published plan, exact selected base, complete base projection | Explicit commit may select target |
| Complete private D4 pair only | Missing published plan; never execute/promote |
| Incomplete D5 preparation anywhere | Abort before selection/application |
| Exact target CurrentV1 visible after interruption | Recover the current file instance and parent, independently of payload completion |
| Base still selected, current preparation present | Recovery reports base; only explicit commit retry may reuse exact complete bytes |
| Truncated/conflicting current preparation | Preserve it and reject commit retry; no repair/cleanup authority |
| Different current ID, digest, generation or historical LF bytes | Conflict; no overwrite |
| Incomplete predecessor links/witnesses/directories or surviving predecessor REMOVE | Reject a new selection |
| Unsupported directory-to-link transition | Reject membership authorization; no directory deletion semantics invented |

The final test record is in [D7](m2.5-d7-reconciliation.md). Namespace outcomes and cause/errno
remain independent; Validation/source errors retain D1/D2/D3/D4/B types; current-preparation
write errors become ExecutionError with preserved errno and namespace outcome. Errors
once current preparation begins are conservatively uncertain. No uncertain
publication is rolled back. Status publication, selected-history policy,
terminal cleanup and pin retirement remain D8/D9 decisions, not hidden defaults.

A v1 predecessor must also declare the exact source values used by every base
membership, including LegacySealDigest/alias bytes and zero-link sources. Matching
a literal destination or witness alone cannot authorize rewriting a selected
source's seal. The metadata compatibility reader uses nonblocking opens before
regular-file checks, preventing corrupt FIFOs from hanging State consumers.
