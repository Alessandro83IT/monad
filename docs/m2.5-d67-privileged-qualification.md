## Resolved fixture regression

The initial failure was `uninitialized generation authority`. The source fixture
attempted to construct `TransactionPins` before explicitly selecting generation
0. Persisted generation documents alone do not initialize selection authority;
the projection-bound namespace requires D6 bootstrap before store/generation
authority binding.

Commit `5b4a37d` makes the fixture publish and commit the empty generation-0 plan
first, release its State lock, construct and abandon `TransactionPins`, then
reacquire State. The selected zero plan is reused by the source test. Fixture
generation directories/documents also receive the required explicit 0700/0600
modes, including under restrictive umask.

The added nonprivileged bootstrap regression checks rejection of pins and GC
before initialization, absence of premature authority binding, rejection of
legacy initialization in the bound namespace, and successful pins/GC after
explicit D6 selection. The correction changes only test files; production code
and privilege gates are unchanged.
