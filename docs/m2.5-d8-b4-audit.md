## Independent GC compatibility review

The only production change outside the new adapter is the pre-existing B4 fix in
`generation::publication::existing_ids_for_gc`. Its historical non-Btrfs branch
still requires directory nlink=2. A nlink=1 directory is accepted only after
`fstatfs` identifies Btrfs and a fresh directory-fd scan rejects every real child
directory with `AT_SYMLINK_NOFOLLOW`. Device/inode, mode, uid/gid, link count and
mtime/ctime are rechecked. Enumeration/open/stat failures propagate before any GC
detach. Effective-owner 0700 directories and regular effective-owner 0600,
single-link generation metadata remain mandatory.

The fix preserves the leaf-directory invariant rather than allowing arbitrary
link counts. Unrelated regular files and non-followed symlinks remain accepted,
matching the historical nlink=2 behavior. Generic `existing_ids` keeps its previous
compatibility listing behavior; only GC's fail-closed validation differs.
The expanded matrix runs on tmpfs (physical nlink=2) and Btrfs (physical nlink=1),
with exact rejection messages and successful rechecks after every restoration.
No synthetic filesystem-type result substitutes for these witnesses. Ext4 and
other filesystems are not physically exercised here; the unchanged branch is
source-reviewed, not labelled a physical PASS.
