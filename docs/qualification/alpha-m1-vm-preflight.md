# Alpha M1 VM read-only preflight

Run `qualification/alpha-m1-vm-preflight.sh` from an interactive shell on the intended Debian qualification VM, before administrative staging or a campaign. The script does not invoke a privileged test, run the canary, write a receipt, install a component, mount a device, or alter fixture/evidence state. It may call `sudo -n -l` solely to display the current account's policy; that command does not run a privileged command. If policy prohibits even that query, omit its output and have the authorized administrator inspect policy separately.

Capture stdout and stderr outside the checkout with the UTC time and boot ID. Do not redirect into an evidence or fixture directory without the evidence custodian's direction. The report includes VM virtualization type, OS release, machine ID, boot ID, failed systemd units and Alpha M1 unit states, installed artifact hashes and metadata, `visudo -c` and current-account sudo policy listing, the read-only build metadata and ordered CTest inventory compared with the reviewed 18 names, build/fixture/D6 mounts, names and metadata below fixture and residual paths, and executable availability relevant to the canary without running it. Record the hypervisor snapshot identifier independently.

`systemd-detect-virt` identifies the current execution environment. A result such as `docker`, `podman`, `container-other`, or `lxc` is a container observation and does not establish the target VM. The script cannot authenticate a VM snapshot or build provenance. Any missing or unreadable path, hash mismatch, non-exact inventory, failed unit, unexpected mount, non-empty fixture, or unverified D6 state is a stop condition. Preserve original logs, backups, receipts, fixture contents, and the D6 residual. Do not interpret preflight output as campaign authorization or Alpha M1 qualification.

After review, reconcile installed hashes against the reviewed candidate manifest and confirm the target VM and snapshot. Continue only under the existing approval process in [alpha-m1-admin-staging.md](alpha-m1-admin-staging.md). This preflight does not replace the canary, administrative staging, or approved execution and evidence review of the exact 18-case campaign.
